# Idea — Create campaigns and scenarios

After the [CDMX geography/map contract](establish-cdmx-geography-and-maps.md), content, objective and save schemas stabilize, refine an authored campaign and scenario system that exercises the same simulation as skirmish. Define a versioned mission/script format, fair triggers and objective states, mission save/replay behavior, an illustrated but data-backed world-map selection view, and a complete playable sequence from arrival to a La Roma battle. Campaign progression, mission prerequisites and rewards must not rewrite independent skirmish maps or assume a regional faction belongs to one neighborhood. Decide with the owner whether persistent conquest, chapter progression or a hybrid is the metagame before funding it. Choose editor scope separately before building its UI; a practical outcome is that a creator can author, validate, load and finish a custom scenario without forking code. Tutorial lessons can use this framework but must keep game rules understandable without cultural context. See the [GDD](../../../docs/design/GDD.md), [build path](../../full-game-build-path.md) and [coverage review](../art-world-coverage-2026-10-21.md).
