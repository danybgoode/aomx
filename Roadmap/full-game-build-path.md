## How to read the order

The steps below are **substantial, durable capability increments**, each resulting in a playable or operable outcome with headless and real-build checks. They are not miniature throwaway versions of the same feature. Codex build speed supports combining related rules, UI, AI and tests inside a wave, while keeping an architecture decision and smoke boundary between waves. Sprints within a funded epic should group coherent outcomes, not a single primitive per sprint. Before each later epic, use `refine` to fix appetite, scope, signal and what it displaces; fund and scaffold it at its Plan gate. The owner has approved this overall direction and order, not yet the unresolved detailed scope or release of every future seed.

## Architectural contract before broad content

- **One simulation:** input adapters emit semantic commands; validation and fixed logical time own outcomes; presentation and audio consume state/events. Godot scenes are views. The same content IDs and command semantics serve desktop, touch, native and Web.
- **Data as product:** faction, unit, building, resource, tech, map and objective definitions have stable IDs, validated schemas and explicit content versions. Rules apply effects; assets never define collision, cost or victory.
- **Replayable state:** canonical update ordering and RNG are explicit; save/load round trips and command replay are checked with state hashes. Cross-platform equality is tested before choosing lockstep. If equality fails, choose a model that tolerates that evidence.
- **Scale evidence:** benchmarks state map size, unit count, route pressure, duration, build type, device and frame/tick budgets. The current 12-unit 20×20 result is the baseline, not the acceptance target for the full game.
- **Design traceability:** for each mechanic, use Age of Empires II: Definitive Edition as the reference; pin the build/patch, mechanical/behavioral/experiential target, any intentional deviation, scenario setup, observed outcome and tolerance before a numerical parity claim. Until then say “AoE2-inspired,” never “parity achieved.”
- **Measurement remains separate:** the game's test-tagged events and accepted public cohorts follow the existing [North Star contract](00-strategy/north-star.md). More features do not convert local matches into eligible cohort evidence.

## Gates that affect scope

Owner decisions: Definitive Edition reference build/patch and deviation policy; final Terrenos fiction; precise conquest and La Roma rules; roster/names and cultural review; multiplayer model after evidence; target devices/army sizes/performance; editor scope, pricing, localization and release sequence. The owner chose the edition and confirmed commercial rights to all three `references/` art sets on 2026-10-16. Record source-level provenance and final export approval during production. The GDD's boards show candidate landmarks, bonuses, rooftop routes and menu entries; their appearance does not approve those mechanics.
