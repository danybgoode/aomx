# Selectable map sizes and discoverable resources

The solo setup exposes three sizes through the Battlefield / map size control: 28×28 Small (La Roma, Narvarte and Copilco), 56×56 La Roma Medium, and 96×96 La Roma Large. Medium and Large start each side with a bicitaxi scout, four separated starter sources, and four distant expansion sources. Each also has eight neutral sites, two for each of Comida, Materiales, Varos and Terrenos. Either side can gather a neutral site after exploring its tile. Explored site locations persist on the minimap under fog.

The medium board is authored in `game/content/maps/la_roma_medium.json`. Its two spawn regions, central district, four obstruction clusters and source positions are balanced by rotation. The large board's eight neutral site anchors are in `game/content/maps/la_roma_large.json`. For each neutral pair, the simulation tries one of five offsets based on the recorded match seed; the second site uses the inverse offset. It checks passability and starting-building clearance before accepting a position. A new solo setup rolls a seed for Medium or Large, while Restart reuses the current seed. Save, replay and network state include the seed and resulting site positions.

The rule and state formats are `godot-4.7.2-skirmish-10` and schema 7. The version change requires a matching client and match host; existing uploaded tester builds contain earlier rules. Small-map starter sources remain at their authored coordinates. A physical long-match balance and crowd-income pass still needs to set the final resource amounts and preferred size for each future team-player count.

Local verification: the pinned Godot CI list passed 35 tests, including the new medium-map test for size, scout discovery, seed repeatability, neutral gathering, save restore and forged-site rejection. The Node suite passed 51 checks with three existing Postgres skips. Deterministic world and Wonder hash fixtures were regenerated for version 10.
