# Strategic opponent: four-player clarity read

**Build:** Restricted `preview-c40b0f5adc5c` · `godot-4.7.2-skirmish-4` / `la-roma-opponent-4`  
**State:** Ready to run after the [private-alpha participant notice](../deploy/alpha/participant-notice.md), individual access and first invitation are approved. No participant has been invited or observed.

## Setup

- Recruit four adult solo RTS players: P1–P2 familiar with the regional references, P3–P4 unfamiliar. Use these IDs in notes; do not record names or contact details here.
- Use one faction per player for all three matches; assign Regios to P1/P3 and Poblanos to P2/P4. Give each player an individual Restricted download key and in-game invite only after the alpha access gates pass. Record the exact build ID from the in-game menu.
- Vary level order to reduce learning effects: P1 Learner→Standard→Challenger; P2 Challenger→Standard→Learner; P3 Standard→Learner→Challenger; P4 Standard→Challenger→Learner. Keep normal game rules and the same authored map. Let each match end naturally or stop at the existing 15-minute draw.
- Read only: “Choose a level, play as you normally would, and say aloud when you notice the opponent changing its plan. I can help with installation or a technical fault, but will not explain its strategy.” Do not teach counters, describe which level should be hardest, or steer toward a victory route.

## After each match

Ask without leading: “What did the opponent seem to be trying? What made this match easier or harder? Did anything feel unfair? What would you try against that behavior next time?” Note the player's exact short phrasing, result, route, duration, technical interruptions and any visible bug. Keep observation separate from interpretation. If a player cannot finish a match, record why rather than replacing the result.

After all three, ask: “Order the three levels from easiest to hardest. What in play led you to that order? Name one specific counter you would try against one of them. Did the setup descriptions match what happened?” Do not reveal the intended order until answers are recorded.
