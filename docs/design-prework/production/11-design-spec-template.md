# 11 — Feature Specification Template

Copy this for each system, unit, technology, building, map or mode.

```markdown
# Feature name
Status: Proposed | Experimental | Approved | Deferred | Rejected
Owner: TBD
Last reviewed: YYYY-MM-DD
Related documents: ...

## Player-facing purpose
What choice or fantasy does this enable?

## Rules
Inputs, state, transitions, outputs, prerequisites, costs, timing.

## Feedback
Visual, audio, HUD, tooltip, error state.

## Interactions
Economy, combat, AI, fog, pathfinding, other techs.

## Edge cases
Blocked, canceled, destroyed, out-of-resources, multiplayer.

## Balance knobs
Named variables; no invented approved numbers.

## Acceptance scenarios
Given/When/Then, including failure cases.

## Art/audio/localization
Assets and cultural review requirements.

## Open questions and decision log
Unresolved issues and rationale.
```
