# Sources and Design References

Consulted 2026-10-13. External links are for human review, not evidence that a specific implementation is available.

- GDDKit, practical GDD: https://www.gddkit.com/guides/how-to-write-a-game-design-document/ — player promise, testable rules, decisions, milestone exits.
- ALLO, Living GDD: https://allo.io/blog/en/game-design-document-template/ — modular hub, feature briefs and decision log.
- Gameheim, GDD wiki: https://www.gameheim.com/docs/game-design-document-wiki — one topic per page, current rule first, centralized numbers.
- Godot 4.5 TileMaps: https://docs.godotengine.org/en/4.5/tutorials/2d/using_tilemaps.html — TileMapLayer and navigation caveats.
- Godot 4.5 Navigation: https://docs.godotengine.org/en/4.5/tutorials/navigation/index.html — navigation architecture.
- Godot release information: https://godotengine.org/releases/4.5/ — 2D navigation changes.
- openage project: https://github.com/SFTtech/openage — initial engine inspiration; not chosen for MVP.
