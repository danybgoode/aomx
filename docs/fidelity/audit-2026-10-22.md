## Reproduction and limitations

From the repo root, each check used `/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script res://tests/<name>.gd` with Godot 4.7.2. Passed: `strategic_economy_test`, `strategic_progression_test`, `warfare_test`, `world_expansion_test`, `strategic_opponent_test`, `strategic_ai_test`, `skirmish_test`, `district_test`, `geography_test`, `skirmish_persistence_test`, `skirmish_replay_test`, and `cross_platform_hash_test`. The first persistence attempt could not write `user://` inside the filesystem sandbox and hung after script errors; it passed on a rerun with the normal local Godot profile. This was an environment failure, not a gameplay defect. Cross-platform hash fixtures passed **on macOS only** in this run.

No downloaded Restricted build, uncoached player task, DE run or numerical reference measurement was performed for this audit. Previous epic records describe their own build evidence; this matrix does not inherit their open owner checks as passed.
